# Contributing

Thank you for helping improve Legendary Wings NES to PC.

## Reporting problems

Use the bug report form in GitHub Issues. Include your build version, Windows version, graphics mode, the level or section, and clear steps to reproduce the issue. Mention whether you loaded a save state. Include a screenshot when it helps explain an artwork problem.

Do not upload ROM files, extracted game assets, save states, memory dumps, or private information.

## Suggestions and changes

The current priority is polishing the first-level remaster while preserving the original gameplay. Later-level artwork will follow in future updates. Open an issue to discuss substantial changes before starting work.

Artwork changes should preserve the native dimensions, playable corridors, collision boundaries, and scrolling behavior. Keep pixel art crisp with nearest-neighbor rendering. Check the affected section in motion and compare both graphics modes with F6.

Only submit work you have permission to share. Keep original ROMs, generated recompilation outputs, build artifacts, and private test captures out of commits.
